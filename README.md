# Indian-Literacy-Rate-Analysis
An interactive Tableau dashboard analyzing India's literacy statistics, highlighting gender-based graduation rates, top literate cities, and state-wise population and literacy ratios

What's inside:
- Top 20 cities with highest effective literacy
- State-wise male/female graduates
- Population ratio by gender
- Literate ratio by state

Tools used:
- Tableau Public
- Dataset from Kaggle

This is just a basic version. More features and filters can be added later.
